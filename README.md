🛍️ Google Merchandise Store E-commerce Analysis
📌 Project Objective

Analyze the Google Merchandise Store GA4 ecommerce dataset to identify the customer, marketing, product, device, and user journey factors driving conversions and purchase revenue using SQL, Google BigQuery, and Tableau.

🎯 Business Problem

The Google Merchandise Store experiences high website traffic, but management lacks visibility into which customer segments, marketing channels, devices, products, and user journeys drive conversions and purchase revenue. This limits data-driven decisions for marketing, product strategy, and user experience improvements.

⚡ Actions Performed
Analyzed 4.3M+ GA4 ecommerce events using Google BigQuery.
Performed 13 SQL analyses covering marketing, customer, product, device, and funnel performance using CTEs, window functions, conditional aggregation, and data validation.
Built an interactive Tableau dashboard with 4 KPI cards to monitor acquisition, purchase revenue, customer behavior, product performance, and conversion metrics.
🛠️ Tools
SQL
Google BigQuery
Tableau
Google Analytics 4 (GA4) Public Sample Ecommerce Dataset
📊 Key Insights
Organic Search generated the highest purchase revenue ($95.8K).
Desktop generated the highest purchase revenue among devices ($208.8K).
Only 7.21% of product viewers completed a purchase.
The largest funnel drop-off (45.49%) occurred between checkout and purchase.
💼 Business Impact

The analysis identified high-performing acquisition channels, customer behavior patterns, and checkout friction, enabling data-driven decisions to improve marketing performance, user experience, and ecommerce revenue.

💡 Recommendations
Optimize the checkout experience to reduce abandonment.
Prioritize investment in high-performing acquisition channels.
Promote top-performing products.
Continuously monitor KPIs through the Tableau dashboard.
